# 제국 월드맵 프로토타입 — 0.0.24

## 현재 적용 상태

최신 사용자 요청은 도시 **40개**다. 앞선 상담의 50개 안보다 이 요청을 우선한다.
지도는 5120×3840, 도시는 128×128 원본 크기이며, 도시 중심 간 거리는 최소 400px이다.
초원과 기존 북쪽 해안만 남겼으며 산·숲·강·도로·교량·농경지는 없다.
도시 이름은 판타지용 임시 명칭이고, 현재 위치는 실제 도시의 지리적 재현이 아니다.

카메라는 방향키 또는 WASD로 이동한다. 속도는 840 화면 픽셀/초(전투맵의 2배)이며,
대각선 이동은 정규화한다. 휠 줌은 1~3배이고 맵 경계를 벗어나지 않는다.
캐릭터 이동 속도는 기존 76px/초이며 우클릭 이동 및 항상 선택 상태를 유지한다.
미니맵 화면 사각형 내부를 왼쪽 버튼으로 잡고 끌면 카메라가 따라간다. 클릭 시 화면이 튀지
않도록 잡은 위치의 오프셋을 유지한다. 밖으로 끌어도 카메라는 경계에 고정되며, 밖에서
마우스 놓기·포커스 손실·리사이즈로 드래그가 종료된다. 사각형 밖을 클릭해 카메라를 순간이동시키는
기능은 없다. 미니맵 우클릭은 캐릭터를 움직이지 않는다.

지형은 빌드 시 한 번 생성하며 2048px 이하인 6개 조각(합계 약 75MiB RGBA)으로 보관한다.
미니맵은 별도의 1024×768 텍스처이고, 원본 지형은 축소하지 않는다. 카메라 이동·줌·리사이즈 때
재생성하지 않는다. `world_layout.json`에 40개 도시 좌표와 6개 조각의 경로·크기를 저장한다.
생성기는 도시가 해안이나 다른 도시와 겹치지 않는지 검증한다. `world_smoke.gd`는 방향키 속도,
1배/3배 미니맵 드래그와 좌표 변환·경계·선택 유지·해제 후 정지·포커스 손실을 검증한다.
브라우저에서 실제 GUI 드래그도 확인한다.

---

아래는 **0.0.23 지형 설계 이력**이며, 산·숲·강·도로와 12개 도시 배치는 현재 버전에서 제거했다.

## 지리적 모티브와 조사 범위

특정 연도의 신성 로마 제국 국경을 재현한 지도가 아니라, 중부 유럽 중심부의 지형 관계를 압축한 가상 제국이다.
북부 저지대와 해안, 서쪽 라인강 계통, 중부 구릉과 혼합림, 동쪽 보헤미아 분지,
남부 알프스와 그 북쪽 다뉴브강 계통을 큰 골격으로 삼았다. 제국은 시대에 따라 영역이 달랐고
북이탈리아 등도 연관되지만, 이번 시안은 독일권·보헤미아·오스트리아와 남쪽 산길에 집중한다.
현재 지리자료는 지형 배치 참고용이며 중세의 숲 면적·강의 세부 물길·정치 경계를 입증하지 않는다.
숲의 밀도, 가상 도시명, 도로와 교량, 성벽 모양, 각 거리와 축척은 게임 디자인 선택이다.

실제로 읽은 공개 자료 (2026-11-07):

- Natural Earth 산지/지리 지역: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_geography_regions_polys.geojson
  ALPS 항목과 유럽 지역을 확인했다.
- Natural Earth 강: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_rivers_lake_centerlines.geojson
  Rhine, Danube, Elbe 수계 좌표를 확인했다. 서쪽의 남북 수계, 남부의 동서 수계, 동북쪽 수계로 단순화했다.
- Natural Earth 도시: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_populated_places.geojson
  Strasbourg (7.750,48.580), Frankfurt (8.675,50.100), Hamburg (9.998,53.552),
  Prague (14.423,50.087), Vienna (16.365,48.202)의 경도·위도를 확인했다.

일반 역사 웹 문서는 실행 환경의 네트워크 제한(HTTP CONNECT 403)으로 읽지 못했다.
위 세 자료는 실제 열람한 현대 지리 데이터이며, 역사 문서를 조사 완료했다고 주장하지 않는다.
이미지나 지도 타일을 복제하지 않고 정수 좌표의 자체 도트 도형으로 새 지형을 생성했다.

## 배치 및 크기

맵: 3072×2304 원본 픽셀. 도시: 개별 128×128 픽셀. 인물: 기존 원본과 scale=1 유지.
카메라: WASD, 휠 1~3배, 맵 경계 제한. 창이 지도보다 큰 경우에는 빈 맵 밖이 보이지 않는 최소 배율로 보정한다. 북쪽 해안, 중앙 구릉, 남쪽 고산지대로 구분한다.
서쪽에 라인강풍 수계, 남쪽 산맥 앞에 다뉴브강풍 수계, 동쪽 분지에서 북쪽으로 엘베강풍 수계를 배치했다.
12개의 요새도시를 도로·교량으로 연결한다. 각 도시는 사각 성벽, 네 모서리 탑, 남문,
내성, 목조 가옥, 붉은 기와/짙은 지붕과 작은 깃발을 갖는다.

## 구현 및 편집

생성기 의존성은 `python -m pip install -r tools/requirements.txt`로 설치한다.

`tools/build_world_map.py`는 고정 시드로 지형·도로·도시를 그린다. `assets/world/imperial_world.png`에
정적 지형을 미리 합성하고 `world_layout.json`에 도시 이름·위치·128×128 크기·모티브를 저장한다.
도시 샘플 4종도 별도 PNG로 남긴다. 기존 구매 캐릭터 에셋은 변경하지 않는다.
지형 RGBA 기준 약 27MiB이며 카메라 이동·확대·창 크기 변경에는 같은 텍스처를 재사용한다.
실시간으로 움직이는 것은 플레이어 한 명, 카메라, 목적지 표시, 읽기 전용 소형 지도뿐이다.

`WorldMap`은 검증된 `BattleMap`의 카메라·이동·발 기준 정렬을 공유하되,
왼쪽 클릭 선택 해제를 비활성화하고 항상 선택된 여행자로 동작한다.
캐릭터 생성 → 월드맵 → 상단 중앙 '전투맵 이동' → 전투맵 상단 '← 월드맵'.
전투맵에서 돌아오면 월드맵 위치·카메라·줌이 복원되고 대기 상태가 된다.
캐릭터 생성 버튼을 다시 누르면 새 출발 위치로 초기화된다.

도시는 표시만 한다. 이번 프로토타입은 직선 이동이며 산·강·도시 충돌, 도로 기반 경로 탐색,
도시 입장, NPC·경제·세력 시스템은 포함하지 않는다. 도로와 교량 역시 현재는 시각 요소이다.

## 검증

`tests/world_smoke.gd`: 생성→월드맵, 12개 도시의 경계·원본 크기, 최초 우클릭 이동,
좌클릭으로 선택이 풀리지 않음, 걷기/도착 대기, 카메라 네 경계·줌·리사이즈,
화면 중앙 전투 버튼, 전투맵 왕복 상태, HUD 입력 제외와 캐릭터 정보 유지.
기존 캐릭터와 전투맵 검사는 계속 실행한다. 웹 브라우저에서도 실제 입력·화면을 확인한다.
