# 캐릭터 디자인 기준 — MedievalFantasyCharacters / 0.0.13

사용자가 구매하여 제공한 MedievalFantasyCharacters.zip의 파츠를 사용한다.
char.zip 완성형 10장, 이전 adventurers 보관 자료, 과거 테스트 이미지·시안은 프로젝트에서 삭제했다.
이미지 생성 모델로 다시 그리거나 색을 바꾸지 않는다. 원본 PNG 127장은 바이트 그대로 보존한다.

## 가져오기

`tools/import_medieval_assets.py ZIP경로`가 Characters, wardrobe 및 선택한 무기 시트의 PNG를 가져온다.
방패·탈것·효과는 이번 캐릭터 편집기에 포함하지 않는다. 머리장비·장갑 자료는 향후 장착용으로 보관한다. Unity 스크립트 실행 없이
.meta의 spriteSheet 사각형을 읽어 Godot의 위쪽 원점 좌표로 변환한다. catalog.json에
원본 SHA-256, PNG 크기, 실제 등록된 파츠 사각형을 저장한다.
문서에는 예전 크기 표기가 있으므로 실제 PNG와 .meta를 기준으로 한다.

## 선택 항목

인간으로 고정하며 생성 화면에는 다음 8개 항목만 표시한다.

- 피부색: 7. 얼굴: 피부 시트당 40.
- 복장 색상: 12. 중복 검정 PNG 2장은 제외.
- 머리 모양: 없음 + 30. 머리 색상: 8.
- 수염 모양: 없음 + 29. 수염 색상: 8.
- 무기: 한손 도끼/한손 둔기/한손 검. 1/3 → 2/3 → 3/3 순환.

성별은 인적사항이다. 성별 변경이 선택 외형을 초기화하지 않는다.
머리·수염의 없음도 1번 선택으로 센다. 종족·손/장갑·모자/투구 선택기는 없다.
손은 human_hand 시트에서 피부와 같은 인덱스의 맨손을 자동 사용한다.
과거 종족/장갑/머리장비 선택값은 normalize에서 제거하므로 생성 외형에 섞이지 않는다.
다른 종족과 모자·투구·장갑의 원본은 보관하지만 생성 외형에는 사용하지 않는다.

## 시작 무기

사용자가 지정한 시트 위치를 그대로 사용한다. 무기 전체 시트의 유효 파츠를 선택하며
그림이 없는 마지막 칸을 검으로 잘못 선택하지 않는다.

| 선택 | 시트 | 파츠 이름 | 위쪽 원점 영역 | 손잡이 기준점 |
| --- | --- | --- | --- | --- |
| 1/3 한손 도끼 | axe.png | axe_0 | (0,0,32,32) | (15,22) |
| 2/3 한손 둔기 | blunt.png | blunt_0 | (0,0,32,32) | (16,25) |
| 3/3 한손 검 | sword.png | sword_12 | (160,32,32,32) | (15,28) |

위치는 catalog.json의 weapons에 저장한다. 무기는 화면 왼쪽 손에 똑바로 세워 쥐며
손잡이 기준점을 매 프레임 손 위치에 맞춘다. 무기를 먼저 그리고 손을 그 위에 얹는다.
공격 동작은 이번 작업에 추가하지 않고 대기·걷기·달리기에 착용 상태를 표시한다.

## 조립과 애니메이션

몸통/머리/시작 무기는 32×32칸, 손은 16×16칸이다.
원본 영역을 그대로 정수 위치에 합성하여 64×64 RGBA 결과를 만든다. 크기·팔레트 변경 없음.
몸통 기준점은 (16,24), 발 기준은 y=56. 머리·머리카락·수염은 같은 원점을 사용한다.
무기를 쥔 손의 기준점은 (20,49)이며 몸통 높이 변화와 이동 시 손 흔들림을 함께 따른다.
원본 몸통 대기 4프레임, 걷기 8프레임, 달리기 8프레임 순서를 사용한다.
머리/손은 대기 [0,1,2,1], 이동 [0,1,0,-1,0,1,0,-1] 픽셀 높이를 따라간다.
대기는 초당 6프레임, 걷기/달리기는 초당 12프레임이다.

선택이 바뀔 때만 애니메이션을 합성한다. 매 프레임 이미지를 재합성하지 않는다.
미리보기 공통 영역은 (8,4,48,56), 최근접 필터를 사용한다. 월드맵에도 같은 SpriteFrames를
넘겨 인물 선택이 유지되며, 발 기준은 월드 y=320이다. 도시·지형과 상호작용 범위는 그대로다.

## 검증

원본 127장 해시/임포트 픽셀/분할 영역, 인간 피부·얼굴, 요청한 세 무기의 정확한 시트 위치,
피부별 양손 픽셀 일치, 모든 대기/걷기/달리기 프레임의 손잡이 정렬과 미리보기 범위,
8개 선택기/순환/제외 항목 부재/성별 독립성, 월드맵 외형 유지 및 발 기준을 tests/smoke.gd에서 확인한다.
