# 캐릭터 디자인 기준 — 개별 PNG / 0.0.19

원본은 사용자 MedievalFantasyCharacters.zip이며, 무기 부분은 최신 weapons.zip으로 교체했다.
art/medieval에 4,573개 파일(PNG 4,567장, GIF 5개, RTF 1개)을 보관한다.
sprites/weapons의 406개 PNG는 새 ZIP과 파일명·바이트가 일치한다. 삭제된 무기는 남기지 않는다.
인물/복장/지형/가이드 원본은 이번 무기 교체에서 변경하지 않는다. 이전 캐릭터 시안은 복원하지 않는다.

## 편집 원본과 런타임

개별 PNG를 편집하고 tools/build_medieval_atlas.py 또는 tools/build-web.sh를 실행한다.
.gdignore로 원본 자동 임포트를 막고, 사용하는 1,288개 파츠를 1024×1024 아틀라스 2장에 묶는다.
원본 크기/색/투명 RGB를 그대로 복사하고 파츠 사이에 1px 여백을 둔다. 보간/재착색하지 않는다.
catalog에 source, SHA-256, size, 숫자 id, atlas, rect를 기록한다. 숫자 정렬하며 결번을 허용한다.
Godot는 process/fix_alpha_border=false, nearest를 사용한다. 임포트 후에도 원본 RGBA를 검증한다.
모자·장갑·탈것 및 발사체/발사 프레임은 원본으로 보관하며 이번 장착 무기로 취급하지 않는다.

## 생성 화면

인간 고정. 상단은 이름·성별·나이(16~40), 하단 왼쪽 액자, 오른쪽 스크롤 없는 두 열이다.
왼쪽은 피부/얼굴/복장/머리/머리색, 오른쪽 위는 수염/수염색/무기다. 성별을 바꿔도 외형은 유지된다.
피부7, 얼굴40, 복장12, 머리 없음+30/색8, 수염 없음+29/색8을 제공한다.
종족/손/장갑/모자/투구 선택기는 없다. 양손은 선택 피부의 인간 손 파츠를 자동 사용한다.
무기 선택은 기존 3종: axe_01 한손 도끼 → blunt_01 한손 둔기 → sword_01 한손 검.
창과 다른 장비를 생성 선택기에 추가하지 않는다. weapon_items에 장착 무기176종을 등록한다.
이후 장비 연결은 외형 설정의 equipped_weapon에 파일명 식별자(예: spear_101)를 지정하면 된다.
투석구의 번호 PNG는 동작 프레임이므로 첫 프레임만 장착 항목으로 등록한다.

## 부착 및 표시

무기 PNG는 32×32, 32×48, 32×64 등 크기가 다르다. 원본을 줄이지 않는다.
시작 무기 손잡이는 도끼(15,21), 둔기(16,23), 검(15,26)이며 나머지는 생성기의 weapon_grip에서
실제 불투명 손잡이 픽셀에 맞춘다. 검은 폼멜 위, 장병기/창은 아래쪽 자루를 잡는다.
손과 무기는 동일 기준점에서 90도 단위로 회전하며 실제 파츠 너비/높이를 사용한다.
합성 캔버스128×96, 몸통 원점(64,40), 발 y=72이다. 추가된 부분은 투명 여백이다.
시작 무기 미리보기는 (32,20,80,56)으로 이전 크기와 위치를 유지한다.
큰 장비는 전체 동작의 사용 영역을 합친 고정 영역으로 표시해 프레임별 확대/이동을 방지한다.
월드맵은 원본 픽셀 크기, 인물 중심 x=374, 발 y=320을 유지한다. 도시/지형은 변경하지 않는다.
대기4장(6fps), 걷기/달리기8장(12fps). 버튼은 대기/걷기/공격이다. 선택 변경 때만 프레임을 합성한다.

## 무기별 공격

spear 폴더의 17종만 thrust_attack, 그 외 장착 무기는 기존 chop_attack을 사용한다.
polearm도 휘두르기다. 번호 결번이나 spear_101~104를 목록 인덱스로 오인하지 않는다.
원본 가이드는 art/medieval/Animation Guide의 chop_attack_sample.gif와 thrust_attack_sample.gif이다.
각각 6장/100ms이며 catalog.attack_references의 경로/해시/지속시간을 기록하고 재생에 적용한다.
몸통과 머리는 고정하며 별도 회복 프레임이나 긴 정지 시간을 추가하지 않는다.

- 내려치기: 수직 대기 → 머리 위 시계90도 준비 → 손/무기를 숨긴 궤적3장 → 반시계90도 마무리.
  weaponfx03의 처음 3장을 (32,37)에 배치한다. 기존 시작 무기 동작을 유지한다.
- 찌르기: 수직 대기 → 왼쪽 수평 준비 → 손/무기를 숨긴 직선 궤적3장 → 왼쪽으로 뻗은 수평 마무리.
  weaponfx02를 반시계90도 회전한다. 대기 손은 창을 세워 잡도록 내려치기보다 위에 둔다.
  수평 준비와 마무리는 같은 높이를 사용하며 앞으로 뻗는 거리를 바꾼다.

전투 판정이나 월드맵 공격 조작은 추가하지 않는다.

## ZIP 교체 및 검증

전체: python tools/import_medieval_assets.py /path/to/MedievalFantasyCharacters.zip
무기만: python tools/import_medieval_assets.py /path/to/weapons.zip --weapons

임시 폴더에서 경로/파일/연결/아틀라스를 검증한 후 교체한다. 무기만 가져오기는 다른 원본을 보존한다.
덮어 합치지 않으므로 삭제 파일이 되살아나지 않는다. 결과의 파일 목록과 바이트를 ZIP과 대조한다.
Python 테스트는 잘못된 ZIP의 무손상 거부, 전체/무기 교체의 삭제 반영과 원본 보존을 확인한다.
Godot 검사는 원본 RGBA, 무기176종의 분류·손잡이·합성 전 경계·고정 미리보기 영역,
가이드 재생 시간, 시작 무기3종/선택기8개/두 열 배치/피부별 손/월드맵 위치를 확인한다.
웹 브라우저에서 생성 화면, 세 무기의 공격 전환, 파츠 변경 및 월드맵 진입을 확인한다.
