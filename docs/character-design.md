# 캐릭터 디자인 기준 — 개별 PNG / 0.0.15

현재 원본은 사용자가 새로 보낸 MedievalFantasyCharacters.zip의 개별 PNG 5,577장이다.
`art/medieval/`에 이름과 바이트를 보존한다. 이전 캐릭터 자료나 생성 시안은 복원하지 않는다.
새 개별 PNG 중 이전 런타임에서 사용하던 파츠 3,852개를 원래 시트 영역과 비교했고 RGBA 차이가 없었다.

## 편집 원본과 런타임

- 편집: `art/medieval/`의 개별 PNG. `.gdignore`로 Godot 자동 임포트를 막는다.
- 생성: `tools/build_medieval_atlas.py`가 실제 사용하는 1,113개 파츠를 1024×1024 아틀라스 2장으로 묶는다.
- 출력: `assets/medieval/atlas_*.png`, `catalog.json`. 원본 크기/색/투명 RGB까지 그대로 붙이며 1px 여백을 둔다.
- 원본과 생성 결과를 픽셀 단위로 비교한다. Godot `process/fix_alpha_border=false`, nearest 필터를 사용한다.
- PNG만 바꾸고 `tools/build-web.sh`를 실행하면 자동 재생성한다. 원래 시트나 Unity .meta는 필요 없다.
- catalog의 슬롯에 source, SHA-256, 원본 size, row/column, atlas, rect를 저장한다.
- 모자·장갑·다른 종족·탈것 등의 원본은 보관하지만 이번 런타임 아틀라스에는 넣지 않는다.

## 생성 화면

인간 고정. 상단은 이름·성별·나이(16~40), 하단 왼쪽은 액자, 오른쪽은 스크롤 없는 두 열의 파츠 목록이다.
왼쪽 열은 피부/얼굴/복장/머리/머리색, 오른쪽 열 상단은 수염/수염색/무기다.
성별은 외형을 초기화하지 않는다. 선택 항목은 다음 8개뿐이다.

- 피부색 7, 얼굴 40, 복장 색상 12.
- 머리 모양 없음+30, 머리 색상 8.
- 수염 모양 없음+29, 수염 색상 8.
- 무기 3: 1/3 한손 도끼, 2/3 한손 둔기, 3/3 한손 검.

종족/손/장갑/모자/투구 선택기는 없다. 양손은 얼굴 피부색과 같은 인간 손 파츠를 자동 사용한다.
무기는 axe__r01_c01, blunt__r01_c01, sword__r02_c06 디자인을 유지한다. 검은 마지막 유효 파츠로 선택했던
13번째 디자인이며 이후 다른 검이 추가되어도 이 식별자는 바뀌지 않는다.

## 조립 및 기본 동작

80×64 캔버스에 정수 좌표로 합성한다. 몸통 기준 (32,24), 발 y=56, 미리보기 영역 (0,4,80,56).
이전보다 좌측 여백을 늘려 손/무기/궤적을 밀어넣지 않고 원래 공격 위치에 그린다. 원본 파츠 크기는 그대로다.
머리/머리카락/수염은 같은 원점. 무기 손잡이 기준점은 도끼 (15,22), 둔기 (16,25), 검 (15,28).
손 기준 (35,49)에 손잡이를 맞추고 그 위에 손을 그린다. 대기 높이는 [0,1,2,1],
걷기/달리기 높이는 [0,1,0,-1,0,1,0,-1]. 대기 4장(6fps), 걷기/달리기 8장(12fps).
달리기 데이터는 유지하지만 생성 화면 버튼은 대기/걷기/공격이다.
선택 변경 시에만 프레임을 합성하며, 화면 갱신마다 원본 파츠를 다시 합성하지 않는다.
월드맵에 같은 SpriteFrames를 넘기며 대기로 재생한다. 월드 발 기준은 y=320이며 캔버스 여백 증가만큼 스프라이트 x를 보정해 인물 위치를 유지한다.

## 공격 기준: 원본 chop_attack_sample.gif

사용자가 새로 제공한 Animation Guide.zip의 문서/PNG/GIF를 docs/asset-guides에 원본으로 보존한다.
기준은 chop_attack_sample.gif이다. GIF의 6프레임은 모두 100ms이고 몸통이 고정되어 있다.
0.0.14에서 섞었던 점프 몸통, 별도 회복 프레임/긴 휴식, 몸 안쪽으로 이동한 복귀 손을 제거한다.
attack_sample_02/03/04의 다른 몸동작은 이번 기본 내려치기와 섞지 않는다.

| 프레임 | 몸통/머리 | 손잡이 좌표 | 회전 | 궤적 |
| --- | --- | --- | --- | --- |
| 0 | 기본 고정 | (35,49) | 0 | 없음 |
| 1 | 기본 고정 | (41,24) | 시계 90도 | 없음 |
| 2 | 기본 고정 | 손/무기 숨김 | 0 | weaponfx03 r01_c01 |
| 3 | 기본 고정 | 손/무기 숨김 | 0 | r01_c02 |
| 4 | 기본 고정 | 손/무기 숨김 | 0 | r01_c03 |
| 5 | 기본 고정 | (32,47) | 반시계 90도 | 없음 |

몸통 0번을 6장 모두 사용하며 머리 높이는 바꾸지 않는다. 손과 무기는 같은 기준점으로 함께 회전한다.
궤적의 원점은 (0,21)이며 캐릭터의 왼쪽에서 지나간다. 기존처럼 얼굴 가까이 붙이지 않는다.
공격은 10fps, 모든 프레임 duration 1.0이며 마지막에서 즉시 첫 자세로 돌아가 0.6초로 반복한다.
chop_timing.json은 업로드 GIF에서 읽은 프레임 수/지속시간으로, 테스트에서 재생 시간과 비교한다.
캔버스 여백을 확보해 긴 검도 복귀 손을 몸 안쪽으로 옮기거나 무기를 축소할 필요가 없다.
전투 판정이나 월드맵 공격 조작은 추가하지 않는다.

## 검증

원본 1,113개 파일 해시와 아틀라스/임포트 RGBA, 선택 무기 식별자, 8개 선택기,
피부별 양손 픽셀, 준비/타격/회복 단계와 궤적, 손잡이 정렬, 미리보기 경계,
원본 GIF와 같은 공격 지속시간 및 반복 복귀, 두 열 배치/스크롤 부재/모든 선택기의 패널 내부 표시, 월드맵 연속성을 tests/smoke.gd에서 확인한다.
웹 브라우저에서 대기/걷기/공격 전환과 세 무기의 공격, 파츠 변경 및 월드맵 진입을 확인한다.
