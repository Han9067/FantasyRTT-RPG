# 캐릭터 디자인 기준 — 개별 PNG / 0.0.14

현재 원본은 사용자가 새로 보낸 MedievalFantasyCharacters.zip의 개별 PNG 5,577장이다.
`art/medieval/`에 이름과 바이트를 보존한다. 이전 캐릭터 자료나 생성 시안은 복원하지 않는다.
새 개별 PNG 중 이전 런타임에서 사용하던 파츠 3,852개를 원래 시트 영역과 비교했고 RGBA 차이가 없었다.

## 편집 원본과 런타임

- 편집: `art/medieval/`의 개별 PNG. `.gdignore`로 Godot 자동 임포트를 막는다.
- 생성: `tools/build_medieval_atlas.py`가 실제 사용하는 1,113개 파츠를 1024×1024 아틀라스 2장으로 묶는다.
- 출력: `assets/medieval/atlas_*.png`, `catalog.json`. 원본 크기/색/투명 RGB까지 그대로 붙이며 1px 여백을 둔다.
- 원본과 생성 결과를 픽셀 단위로 비교한다. Godot `process/fix_alpha_border=false`, nearest 필터를 사용한다.
- PNG만 바꾸고 `tools/build-web.sh`를 실행하면 자동 재생성한다. 원래 시트나 Unity .meta는 필요 없다.
- catalog의 슬롯에 source, SHA-256, 원본 size, row/column, atlas, rect를 저장한다.
- 모자·장갑·다른 종족·탈것 등의 원본은 보관하지만 이번 런타임 아틀라스에는 넣지 않는다.

## 생성 화면

인간 고정. 상단은 이름·성별·나이(16~40), 하단 왼쪽은 액자, 오른쪽은 세로 파츠 목록이다.
성별은 외형을 초기화하지 않는다. 선택 항목은 다음 8개뿐이다.

- 피부색 7, 얼굴 40, 복장 색상 12.
- 머리 모양 없음+30, 머리 색상 8.
- 수염 모양 없음+29, 수염 색상 8.
- 무기 3: 1/3 한손 도끼, 2/3 한손 둔기, 3/3 한손 검.

종족/손/장갑/모자/투구 선택기는 없다. 양손은 얼굴 피부색과 같은 인간 손 파츠를 자동 사용한다.
무기는 axe__r01_c01, blunt__r01_c01, sword__r02_c06 디자인을 유지한다. 검은 마지막 유효 파츠로 선택했던
13번째 디자인이며 이후 다른 검이 추가되어도 이 식별자는 바뀌지 않는다.

## 조립 및 기본 동작

64×64 캔버스에 정수 좌표로 합성한다. 몸통 기준 (16,24), 발 y=56, 미리보기 영역 (8,4,48,56).
머리/머리카락/수염은 같은 원점. 무기 손잡이 기준점은 도끼 (15,22), 둔기 (16,25), 검 (15,28).
손 기준 (20,49)에 손잡이를 맞추고 그 위에 손을 그린다. 대기 높이는 [0,1,2,1],
걷기/달리기 높이는 [0,1,0,-1,0,1,0,-1]. 대기 4장(6fps), 걷기/달리기 8장(12fps).
달리기 데이터는 유지하지만 생성 화면 버튼은 대기/걷기/공격이다.
선택 변경 시에만 프레임을 합성하며, 화면 갱신마다 원본 파츠를 다시 합성하지 않는다.
월드맵에 같은 SpriteFrames를 넘기며 대기로 재생한다. 월드 발 기준은 y=320이다.

## 공격 가이드 적용

참고: 새 ZIP의 `Animation Guide/chop_attack_sprite/` 6장과 이전 원본 설명서
`docs/asset-guides/Animation Guide.rtf`, 원본 ChopAttack의 동작 구성.
설명서의 '손과 무기 연결 → 뒤로 90도 준비 → 손/무기 대신 타격 궤적 3장 → 앞으로 90도 → 복귀'를 따른다.
새 그림을 생성하거나 몸/머리를 늘이지 않는다. 가이드의 대안대로 기존 점프 몸통을 사용한다.

| 프레임 | 몸통 인덱스 | 머리 높이 | 손/무기 | 궤적 |
| --- | --- | --- | --- | --- |
| 0 | 0 대기 | 0 | 기본 자세 | 없음 |
| 1 | 22 점프 3 | -2 | 손을 머리 위로, 시계 방향 90도 | 없음 |
| 2 | 21 점프 2 | +1 | 숨김 | weaponfx03 r01_c01 |
| 3 | 21 | +1 | 숨김 | r01_c02 |
| 4 | 21 | +1 | 숨김 | r01_c03 |
| 5 | 0 | 0 | 반시계 방향 90도, 휘두른 뒤 자세 | 없음 |
| 6 | 0 | 0 | 기본 자세 복귀 | 없음 |

0~5는 가이드의 6단계이며 6은 반복 미리보기의 회복/휴식이다. 12fps 기준 지속시간 배수는
[1.5,1.5,1,1,1,1,4]. 미리보기는 SpriteFrames의 실제 프레임별 지속시간을 따라 반복 재생한다.
세 무기는 각 손잡이 기준점을 중심으로 손과 함께 회전한다. 90도 회전으로 픽셀과 색을 보존한다.
회복 시 검이 액자 밖으로 잘리지 않도록 손 위치를 조정한다. 궤적은 원본 효과를 그대로 사용한다.
전투 판정이나 월드맵 공격 조작은 추가하지 않는다.

## 검증

원본 1,113개 파일 해시와 아틀라스/임포트 RGBA, 선택 무기 식별자, 8개 선택기,
피부별 양손 픽셀, 준비/타격/회복 단계와 궤적, 손잡이 정렬, 미리보기 경계,
공격 지속시간 및 반복 복귀, 월드맵 연속성을 tests/smoke.gd에서 확인한다.
웹 브라우저에서 대기/걷기/공격 전환과 세 무기의 공격, 파츠 변경 및 월드맵 진입을 확인한다.
