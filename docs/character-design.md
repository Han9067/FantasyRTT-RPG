# 캐릭터 디자인 기준 — char.zip / 0.0.11

현재 기준은 사용자가 제공한 char.zip의 완성된 PNG 10장입니다. 이전에 생성했던 시안이나
절차적 캐릭터 생성기는 더 이상 기준이 아닙니다. 새 외형, 장비, 행동을 제작할 때 이 파일을 참고합니다.

## 파일과 실제 도트 크기

- 남녀 각 1종: 대기 1장, 이동 4장. 파일명 walking1 → walking2 → walking3 → walking4 순서입니다.
- 모든 원본 캔버스는 **64×64**, RGBA 투명 배경입니다.
- 10장 모두 실제 그림의 경계는 **x=23…38, y=17…46**, 즉 **16×30픽셀**입니다.
- 알파값은 0과 255만 있습니다. 반투명 테두리, 흰 배경, 흐림이 없습니다.
- 남성은 프레임별 불투명 색 16~18개, 여성은 22개를 사용합니다.
- 전체 캔버스 및 그림 위치가 일치합니다. 개별 프레임을 잘라 재정렬하거나 늘이지 않습니다.
- 파일 이름만 정리해 복사했으며 바이트는 동일합니다. source_manifest.json에 원본 파일명,
  저장 경로, SHA-256 및 경계값을 기록했습니다.

## 형태와 복장

공통으로 오른쪽 측면의 큰 머리와 짧고 가는 몸, 한쪽 눈·귀·옆얼굴이 보이는 형태입니다.
머리는 전체 높이의 약 절반을 차지하고, 겹쳐 보이는 팔과 다리로 측면 자세를 표현합니다.
단색 덩어리와 작은 명암 단계, 짙은 외곽선이 특징입니다. 기하학적인 확대 도형으로
다시 그리거나 색상 수를 강제로 줄이지 않습니다.

남성은 갈색의 옆으로 흐르는 머리, 아이보리색 긴소매 상의, 갈색 계열 허리띠와 신발,
어두운 하의를 사용합니다. 여성은 금발 단발, 선명한 파란 상의, 어두운 하의와 신발을
사용합니다. 여성의 복장을 남성의 이전 프롬프트에 맞춰 바꾸지 않습니다.

이동은 팔과 다리가 교차하는 네 자세입니다. 원본 픽셀과 순서를 그대로 사용하고,
프레임당 210ms로 기존 0.84초의 한 주기를 유지합니다. 대기는 원본 1장을 고정 표시합니다.

## 게임 표시와 보존

현재 원본은 머리와 몸이 합쳐진 PNG입니다. 기존 분리 레이어 방식에 맞추려고 이미지를
임의로 자르거나 다시 합성하지 않고, 원본 전체를 직접 불러옵니다.

생성 화면에서는 공통 영역 (20,14)-(42,50)을 AtlasTexture로 보여 줍니다. 투명 여백만
덜 보이게 하는 표시 설정이며 원본 파일이나 동작의 위치는 바꾸지 않습니다. 최근접 필터를
사용하고, 월드맵에서는 원본 1픽셀=1월드 단위로 표시합니다. 실제 높이는 30월드 단위로
기존 캐릭터·도시의 크기 관계를 유지하며, 발바닥 아래 기준선은 월드 y=320입니다.

게임의 외형 목록은 남성 01, 여성 01만 있습니다. 이전 활성 측면 외형 8종과 생성기는
삭제했습니다. 더 오래된 업로드 원본 assets/adventurers는 보관 자료로만 남기고 웹 빌드에서
제외합니다. 게임에서는 읽지 않습니다.

## 무기 확장 시 기준

장착 무기는 별도 레이어로 만들고 손 위치에 맞춘 프레임별 부착 지점을 정의할 수 있습니다.
검·창 등의 전후 가림 순서도 프레임에 맞춰야 합니다. 이번 버전에는 무기를 추가하지 않습니다.
휘두르기·찌르기·막기, 양손 무기나 활의 준비 자세는 몸의 자세가 달라져 전용 동작이 필요합니다.
