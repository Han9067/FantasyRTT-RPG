# 캐릭터 디자인 기준 — MedievalFantasyCharacters / 0.0.12

사용자가 구매하여 제공한 MedievalFantasyCharacters.zip의 파츠를 사용한다.
char.zip 완성형 10장, 이전 adventurers 보관 자료, 과거 테스트 이미지·시안은 프로젝트에서 삭제했다.
이미지 생성 모델로 다시 그리거나 색을 바꾸지 않는다. 원본 PNG 124장은 바이트 그대로 보존한다.

## 가져오기

`tools/import_medieval_assets.py ZIP경로`가 Characters 및 wardrobe의 필요한 PNG만 가져온다.
무기·방패·탈것·효과는 이번 캐릭터 편집기에 포함하지 않는다. Unity 스크립트 실행 없이
.meta의 spriteSheet 사각형을 읽어 Godot의 위쪽 원점 좌표로 변환한다. catalog.json에
원본 SHA-256, PNG 크기, 실제 등록된 파츠 사각형을 저장한다.
문서에는 예전 크기 표기가 있으므로 실제 PNG와 .meta를 기준으로 한다.

## 선택 항목

- 종족: 인간/엘프/고블린/오크, 기본 인간.
- 피부색: 인간 7, 엘프 8, 고블린/오크 4. 얼굴: 종족별 피부 시트당 40.
- 복장 색상: 12. 중복 검정 PNG 2장은 제외.
- 머리 모양: 없음 + 30. 머리 색상: 8.
- 수염 모양: 없음 + 29. 수염 색상: 8.
- 손·장갑: 피부색 연동 맨손 + 장갑 12.
- 모자·투구 종류: 없음/천/밀짚/가죽/장식 가죽/금속/장식 금속.
- 모자·투구 모양: 종류에 따라 1/49/5/37/4/47/23.
- 모자·투구 색상: 천과 장식 금속은 8, 나머지는 1.

성별은 인적사항이다. 원본에 성별 분류가 없으므로 같은 파츠를 모두 사용할 수 있고,
성별 변경이 선택 외형을 초기화하지 않는다. 머리·수염의 없음도 1번 선택으로 센다.
모자·투구를 쓰면 머리카락을 숨기며 선택값은 보존한다. 종류 변경 시 하위 선택값은
해당 범위로 보정한다. 좌우 버튼은 첫/마지막 항목 사이를 순환하고 선택지가 하나면 비활성이다.
wardrobe는 모자·투구 시트이며 별도 흉갑·바지 파츠가 아니다.

## 조립과 애니메이션

몸통/머리는 32×32칸, 손은 16×16, 장식 머리장비는 32×48칸이다.
원본 영역을 그대로 정수 위치에 합성하여 64×64 RGBA 결과를 만든다. 크기·팔레트 변경 없음.
몸통 기준점은 (16,24), 발 기준은 y=56. 머리·머리카락·수염은 같은 원점을 사용한다.
머리장비는 기본 -5px, 높이 48일 때 추가 -16px로 정렬한다.
원본 몸통 대기 4프레임, 걷기 8프레임, 달리기 8프레임 순서를 사용한다.
머리/장비는 대기 [0,1,2,1], 이동 [0,1,0,-1,0,1,0,-1] 픽셀 높이를 따라간다.
대기는 초당 6프레임, 걷기/달리기는 초당 12프레임이다.

선택이 바뀔 때만 애니메이션을 합성한다. 매 프레임 이미지를 재합성하지 않는다.
미리보기 공통 영역은 (8,4,48,56), 최근접 필터를 사용한다. 월드맵에도 같은 SpriteFrames를
넘겨 인물 선택이 유지되며, 발 기준은 월드 y=320이다. 도시·지형과 상호작용 범위는 그대로다.

## 검증

원본 124장 해시/임포트 픽셀/분할 영역, 모든 피부·얼굴·머리장비 조합,
선택기 순환/종속 항목 범위/성별 독립성/상하 패널 배치/스크롤/4·8·8프레임,
월드맵 외형 연속성·발 기준 및 이전 리소스 제거를 tests/smoke.gd에서 확인한다.
