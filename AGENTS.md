# Project conventions

- Current release: 0.0.31; next completed update: 0.0.32. Increment only the patch once per delivered game update. Never change the first two components unless asked.
- Validate playable changes, push editable source to main, and publish builds/web to gh-pages for the existing GitHub Pages site.
- The visual source of truth is the purchased user-supplied MedievalFantasyCharacters.zip. Read docs/character-design.md before changing characters.
- Preserve loose source PNGs in art/medieval (.gdignore). Build assets/medieval atlases/catalog with tools/build_medieval_atlas.py; do not hand-edit generated images. Runtime uses only needed parts. Preserve original RGBA; no AI redraws, recolouring or resampling.
- The creator has personal details only at the top, and a portrait on the lower left with two columns of part selectors without scrolling (beard/beard color/weapon at upper right) on the right. Gender is independent of appearance. Creator is human-only; hats/gloves/race have no selectors. Bare hands follow skin. The weapon selector cycles only axe_01.png, blunt_01.png, sword_01.png in that order. Keep headgear/glove source assets for future equipment; mounts remain excluded.
- Compose 128x96 frames at integer coordinates; preserve the original 80x56 starter preview crop/scale, expand one shared crop only for larger equipment. Idle/walk/run have 4/8/8 frames; attack has 6 frames at 10fps, matching the weapon-specific chop_attack_sample.gif or thrust_attack_sample.gif with fixed body/head and no extra recovery pause. spear is thrust_attack; every other held weapon uses chop_attack. Preview controls are idle/walk/attack; respect per-frame durations. Head/accessory offsets follow the body. Use nearest filtering. World/battle feet are the unit position.
- Legacy assets/characters, assets/adventurers, tests/fixtures, and tools/references were explicitly removed by the user. Do not restore them.
- Character creation enters WorldMap. WorldMap extends BattleMap movement/camera but is always selected, ignores left-click selection, and uses a static 5120x3840 map transcribed from the user planning image, with plains/forest/mountains/water and 42 native 96x96 cities numbered 1..42 (six <=2048px terrain chunks and a 1024x768 minimap). World camera speed is 840 screen px/s (2x battle), supports arrows and WASD, and the minimap viewport rectangle can be dragged with a stable grab offset, clamped edges and no party orders. Use art/world/tiled/WorldMap.tmx as the current editable terrain/city source; no procedural replacement layouts or old city names. Read docs/world/world-prototype.md for geography references and prototype limitations. The centered top button enters BattleMap; its return button restores world position/camera/zoom. Do not change battle mechanics while working on the campaign prototype. Battle uses a fixed 2560x1600 world, a bounded Camera2D with WASD pan and cursor-anchored wheel zoom 1x..3x, and a CanvasLayer HUD. Sprite scale stays 1; minimum camera zoom shows native pixels. Keep nearest filtering, central spawn, click/four-direction box selection, selection-gated right-click walk orders and idle on arrival. All pointer positions must pass through the camera canvas transform; HUD hit areas remain in screen coordinates. UI screens restore canvas_items scaling. Terrain is a static procedurally baked texture with deeper green grass and no stone decorations; do not regenerate it on camera movement, zoom or window resizing.
- Run meaningful smoke checks for source integrity, selector boundaries/dependencies, layout, preview animations, and world continuity, run tests/world_smoke.gd for campaign transitions/persistent selection/camera bounds and tests/battle_smoke.gd for selection/movement/camera bounds/zoom/HUD checks, then verify the web UI in a browser before publishing. Verify the matching GitHub Pages Actions deployment succeeds before reporting the site ready; GitHub web Actions pages work when the API/site are blocked. Share the full game URL, not a renamed link.

- Current source tree contains 4,573 files: the cleaned character ZIP with its weapons subtree replaced by the latest weapons.zip (406 PNGs); axe_01.png is overridden by the subsequently uploaded axe_01.zip. Numbered filenames replace __rNN_cNN. Full ZIP imports validate in staging and replace old trees; never merge removed files back. Guides live only in art/medieval/Animation Guide.

- docs/weapons/weapon-name-proposals-ko.txt and .csv are review-only name proposals for 109 equipment appearances, excluding shield/polearm/ammunition; sling animation frames are aliases, not separate weapons. Do not apply proposed names or stats to gameplay without a request.

- Active campaign source: art/world/tiled is the exact approved MedievalMap_completed.zip project, using PixelMapCreator PNGs. The City layer uses only the user's original 3x3 (96px) sample at 42 positions; CityPoints provides centers/numbers. The northern snow area is now grass. Preserve the existing GroundTiles-based wide rivers in this approved iteration; RiverTiles changes require a new request. Original PNGs must remain unmodified.
- tools/build_world_map.py validates render-manifest.json source hashes, crops the approved full-size Tiled render into six native chunks, derives city metadata from CityPoints and updates the minimap/review image. Normal builds need Pillow; after deliberate TMX/TSX/PNG edits run tools/build_world_map.py --refresh-render with tmxrasterizer on PATH or TILED_RASTERIZER set (and its normal library environment). This prevents silently exporting stale maps. tests/world_plan_check.py checks every terrain pixel against the Tiled delivery, all 42 exact city pixels/anchors and the minimap. Runtime does not regenerate terrain on camera changes.
- art/world/resources, art/world/tiles, the older traced plan and tools/world_tiles.py are historical references only, excluded from runtime by art/world/.gdignore. Do not restore their old procedural terrain or 128px city sprites to the live map.

- World party presentation (0.0.31): WorldPartyMarker is a native 32x32 token centered at unit_position. Preserve supplied assets/world/party/wObj1.png and wObj2.png. Draw original white wObj2, the selected character clipped with the FULL original wObj2 alpha (including partially transparent edge pixels), then original wObj1. Never tint, rescale, dilate or reshape either source image or inset the mask. The world portrait is ONLY idle frame 0 in its own single-frame SpriteFrames; no playback or direction flipping during any travel/return. Never mutate the shared battle/creator frames. Keep native 1x pixels. The marker replaces world ground shadow/selection ellipse.
