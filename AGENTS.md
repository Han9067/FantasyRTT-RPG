# Project conventions

- The main menu displays the current release as `버전 : 0.0.N`.
- Current release: 0.0.2. For each subsequent completed user-requested update, increment the last component by one (next: 0.0.3). One increment per delivered update, not per commit or build attempt.
- Never change either of the first two version components unless the user explicitly requests it.
- Keep the project.godot application version and main menu display in sync.
- Deliver playable changes to the existing GitHub Pages site by updating the `gh-pages` branch after validation; keep editable source on `main`.
- Characters use original low-resolution pixel art with a right-facing side profile; preserve hard pixel edges.

- All eight selectable characters should look like young adults; avoid beards, aged faces, exaggerated noses or hunched silhouettes.
