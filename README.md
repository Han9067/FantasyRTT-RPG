# 분열의 시대 · FantasyRTT-RPG

마법 없는 중세 내전 세계를 배경으로 하는 2D 도트 전략 RPG의 첫 프로토타입입니다.
현재 웹 버전은 0.0.4입니다 (0.0.1부터 번호를 다시 시작한 웹 버전). 메인 메뉴 → 캐릭터 생성 → 제국 월드맵으로 진행하며, 월드맵 상단 중앙에서 전투 시험장으로 이동할 수 있습니다. 상세 기준은 docs/world/world-prototype.md를 참고하세요. 아래 이전 버전 기록은 개발 이력입니다.

0.0.4: 선택한 플레이어에 흰색 외곽선을 표시합니다. 보병은 체력 10·공격력 4, 플레이어는 체력 100·공격력 6입니다. 아군 선택 후 적 위의 칼 커서에서 좌클릭 또는 우클릭하면 대형으로 접근한 뒤 근접 공격하며, 후열도 빈자리로 전진합니다. 적은 근접 교전에 반격합니다. 공격은 초당 1회이고, 피격 체력바는 마지막 피격 후 4초 동안 표시됩니다. 일시정지 중 공격 예약이 가능하며, 이동·공격·체력바 시간은 함께 멈춥니다.

0.0.3: 깃발을 직전 버전보다 왼쪽 4px·위쪽 4px 더 이동했습니다.

0.0.2: 부대 간격을 가로·세로 1px 넓히고 깃발을 왼쪽으로 3px 조정했습니다. 하단 명령 아이콘을 제거하고 아군 파란색·적군 빨간색 이동 경로선과 왼쪽 위 일시정지 버튼을 추가했습니다. 일시정지 중에도 선택·우클릭 명령·카메라 조작이 가능하며, 노란 테두리가 꺼지도록 다시 누르면 예약한 목적지로 이동합니다.

0.0.1: 전투 유닛은 배치 시와 이동 후 대기 전환 시 임의의 프레임부터 대기 애니메이션을 재생합니다. 대기 중에는 현재 재생 흐름을 유지합니다.

## 웹 실행

https://han9067.github.io/FantasyRTT-RPG/

테스트 링크에는 `?v=버전-빌드시각`을 붙입니다. 각 빌드는 JS·WASM·PCK 파일 이름에도 같은 식별자를 사용하므로 버전 번호를 재사용해도 이전 게임 데이터와 섞이지 않습니다. 최신 링크는 배포한 `build-info.json`의 `test_url`에 기록합니다.

앞으로 테스트 빌드는 이 주소에 갱신합니다. Windows 실행 파일은 기본 배포 대상이 아니며 Git에 포함하지 않습니다.

## 편집기 실행

Godot 4.6.3에서 `project.godot`를 가져온 뒤 F6가 아닌 F5로 프로젝트를 실행하세요.
추가 플러그인이나 서비스, 비밀 키는 필요하지 않습니다.

새 게임 → 위쪽 인적사항(이름·성별·나이) → 아래쪽 파츠 선택 → 캐릭터 생성.
아래쪽 왼쪽 액자에서 대기·걷기·공격을 확인하고, 오른쪽 두 열의 좌우 버튼으로
피부·얼굴·복장·머리·수염·시작 무기를 조합합니다. 오른쪽 열에서 무기1 종류·번호와 무기2 종류·형태를 순서대로 선택합니다. 양손무기를 고르면 무기2는 미장착으로 바뀝니다.
현재 번호/전체 개수를 표시하며 성별을 바꿔도 선택한 외형은 유지합니다.
하단 캐릭터 생성 버튼은 선택한 외형으로 비상호작용 월드맵에 진입합니다.
가제는 '분열의 시대'이며 추후 변경할 수 있습니다.

## 클라우드에서 검증

```sh
cd /workspace/FantasyRTT-RPG
export XDG_DATA_HOME=/workspace/.godot-runtime/data
export XDG_CONFIG_HOME=/workspace/.godot-runtime/config
export XDG_CACHE_HOME=/workspace/.godot-runtime/cache
godot --headless --editor --import --quit
godot --headless --script res://tests/smoke.gd
```

GUI가 있는 환경에서는 `godot --path .`로 실행합니다.

현재 캐릭터는 사용자가 제공한 MedievalFantasyCharacters.zip의 원본 파츠를 조합합니다.
대기 4장·걷기 8장·달리기 8장을 사용합니다. 생성 외형은 인간이며 손은 피부색을 따릅니다.
무기는 한손 도끼·한손 둔기·한손 검 중 하나를 고릅니다. 모자·장갑은 추후 장착용 자료로 보관합니다.
자세한 기준은 [캐릭터 디자인 문서](docs/character-design.md)에 있습니다.
이전 캐릭터 이미지와 보관용 외형 자료는 프로젝트에서 삭제했습니다.
한국어 글꼴은 Noto Sans CJK이며 사용 조건은 assets/fonts/LICENSE.txt에 있습니다.

## 웹 테스트 배포

`tools/build-web.sh`로 Godot 4.6.3의 Web 내보내기를 실행합니다.
같은 버전의 공식 export templates가 필요합니다. 단일 스레드 빌드이므로
GitHub Pages에서 별도 COOP/COEP 헤더 없이 실행할 수 있습니다.
`builds/web/`의 전체 파일이 배포 대상이며 `.wasm`과 `.pck`도 함께 필요합니다.

GitHub Pages를 사용할 경우 저장소 Settings → Pages → Build and deployment에서
Deploy from a branch, `gh-pages` 브랜치, `/ (root)`를 선택합니다.
소스는 main, 실행용 웹 파일은 gh-pages에 보관합니다.

## 버전 0.0.1

메인 메뉴 하단에 버전을 표시합니다. 이후 요청 단위 업데이트마다 마지막 숫자만 1 증가하며,
앞의 두 숫자는 사용자가 명시적으로 요청할 때만 변경합니다.
외형은 전투용 확장을 고려한 오른쪽 측면의 원본 32×48 픽셀 아트 8종입니다.
남성은 짧은 머리와 수염, 금발, 긴 수염, 머리띠와 묶은 머리로 구분하고,
여성은 땋은 머리, 낮게 묶은 머리, 짧은 단발, 높은 묶음 머리로 구분합니다.

## 버전 0.0.2

남녀 8종의 측면 외형을 모두 젊은 성인으로 다시 제작했습니다.
수염과 과도한 얼굴 음영을 제거하고 얼굴, 코, 턱과 몸의 비율을 조정했습니다.
현재 남성은 갈색 앞머리, 금발, 검은 짧은 머리, 적갈색 가르마로 구분하고,
여성은 어깨 길이 머리, 낮은 포니테일, 단발, 땋은 머리로 구분합니다.
외형 선택 카드에도 최근접 픽셀 필터를 적용했습니다.


## 버전 0.0.3

얼굴의 픽셀 크기를 유지하고 몸통을 짧게 줄인 SD 측면 외형으로 개편했습니다.
팔과 다리가 앞뒤로 겹치는 측면 구조이며 각 외형마다 대기 4프레임(4fps),
이동 8프레임(10fps)의 반복 애니메이션을 제공합니다. 생성 화면의 대기/이동 버튼으로
액자 속 동작을 전환할 수 있습니다.

캐릭터 생성 시 선택한 외형과 이름을 가진 인물이 초원 월드맵에 나타납니다.
사각 성곽의 요새도시 그레이워치 한 곳, 산맥, 초원, 나무와 길을 배치했습니다.
지도 이동, 도시 클릭, 전투 등의 상호작용은 없습니다. 캐릭터 버튼으로 생성 화면으로 돌아갈 수 있습니다.

검증은 8종의 프레임 수와 중복 여부, 이름·외형 전달, 월드맵 전환 및 고정 위치를 확인합니다.

## 버전 0.0.4

8종 모두 몸통과 팔다리 내부의 색 면적을 넓힌 통통한 SD 체형으로 수정했습니다.
의상색에 가까운 외곽과 넓은 하이라이트를 사용하고, 측면 방향과 젊은 인상을 유지했습니다.
애니메이션은 대기 2프레임(2fps), 이동 4프레임(6fps)입니다.

월드맵 도시·산맥의 크기와 도로 배치를 유지하고, 성벽 벽돌과 창틀, 지붕 기와와 목조 구조,
산의 암석 층, 나뭇잎 덩어리, 풀과 작은 꽃, 길의 자갈 표현을 추가했습니다.
캐릭터와 지형 모두 경계색·중간색·밝은 색의 도트 면으로 형태를 표현합니다.


## 버전 0.0.5

사용자가 제공한 「모험가_외형_전체_64종.zip」의 캐릭터로 교체했습니다.
선택 목록은 요청에 따라 남성 01–04, 여성 01–04입니다. 나머지를 포함한 64종의
얼굴·몸통 원본 시트는 assets/adventurers에 보관하며 그림을 다시 그리거나 변형하지 않습니다.

얼굴과 몸통은 같은 32×36 투명 캔버스에 저장되어 있습니다. 원본 몸통 위에 얼굴을
(0,0)에 합성하고 최근접 필터로 표시합니다. 원본의 1·3번째 대기 프레임과
2·4·6·8번째 이동 프레임을 사용하여 2/4프레임 구성을 유지합니다.
대기 660ms/프레임, 이동 210ms/프레임으로 원본의 전체 반복 시간을 유지합니다.

테스트는 업로드된 full 시트를 정답 자료로 사용하여 선택된 8종의 48프레임 전체에서
알파와 보이는 픽셀이 원본과 일치하는지 확인합니다. 완전 투명 픽셀의 RGB는
Godot의 알파 경계 보정으로 달라질 수 있으나 화면에는 영향을 주지 않습니다.


## 버전 0.0.6

업로드된 모험가의 큰 머리·짧은 몸 비율과 색을 바탕으로 남녀 01–04의 오른쪽 측면을 제작했습니다.
한쪽 눈과 귀가 보이는 얼굴, 겹쳐진 어깨와 팔, 측면 허리띠와 앞뒤 발로 구성합니다.
원본은 assets/adventurers에 그대로 보관하고 게임은 assets/adventurers_side의 새 시트를 사용합니다.
머리와 몸통은 각각 32×36 투명 캔버스에 분리되어 있으며 대기 2장·이동 4장으로 구성됩니다.

`godot --headless --path . --script res://tools/draw_side_adventurers.gd`는 새 측면 시트만 재생성합니다.
기존 원본 비교 검증과 별도로 48개의 측면 프레임, 레이어 경계, 애니메이션과 화면 전환을 검증합니다.


## 버전 0.0.7

사용자가 승인한 대기 및 이동 2장 시안을 실제 32×36픽셀 격자로 옮겼습니다.
기준 시안은 tools/references/approved_male_01.png에 보관합니다. 모든 포즈에 하나의
배율을 적용하고 머리 위치를 정렬하며, 이동 중에는 동일한 머리 레이어를 재사용합니다.

대기 자세의 보이는 발끝에서 가로 한 열(1픽셀)을 줄이고 뒤쪽 발의 어두운 부분을 드러냈습니다.
대기 2프레임은 가벼운 호흡이며 발 위치는 고정입니다. 이동은 앞뒤 다리가 서로 바뀌는
대각선 접지 자세 2프레임으로 변경했습니다. 420ms 간격으로 반복합니다.

남녀 각 4종은 동일한 체형·동작에 기존 외형의 머리 모양과 색을 적용합니다.
머리·몸통 레이어는 계속 분리하며, 월드맵 크기 및 비상호작용 구성은 유지합니다.
검증에는 발끝 1픽셀 수정, 반대 발 노출, 대기 발 고정, 이동 머리 고정도 포함됩니다.


## 버전 0.0.8

0.0.7에서 승인된 시안을 32×36픽셀·12색으로 다시 샘플링해 외형이 달라지던 문제를 수정했습니다.
현재는 2172×724 기준 이미지에서 동일 크기의 512×704 영역을 위치만 맞춰 추출합니다.
남성 01의 색·음영·투명도 및 프레임별 머리를 보존하고, 요청한 대기 발끝의 한 원본 픽셀
윤곽 조정만 적용합니다. 머리와 몸통은 서로 겹치지 않는 영역으로 분리해 다시 합성합니다.
임의로 만든 호흡 자세를 제거하여 승인된 대기 1장과 이동 2장(420ms 간격)을 사용합니다.

남녀 각 4종 모두 원본 해상도의 같은 몸동작을 사용하며, 나머지 7종은 음영을 보존하는
색상 변경과 기존 헤어 장식으로 구분합니다. 월드맵 표시 배율을 별도로 지정해 도시와
캐릭터의 크기 관계를 유지합니다. 생성 화면은 축소된 게임용 도트를 확대하지 않고 원본
텍스처를 액자 크기에 맞춰 표시합니다.

검증은 실제 Godot 임포트·레이어 합성 결과를 승인된 기준 이미지의 모든 픽셀과 비교합니다.
대기 발끝의 제한된 수정 영역 외에는 보이는 색과 투명도가 같아야 합니다. 기존 업로드 원본
보존, 남녀 8종 선택, 이름·나이, 애니메이션, 월드맵 전환 및 표시 크기도 확인합니다.


## 버전 0.0.9

머리색 변경이 갈색 눈동자까지 적용되어 남성 03의 눈이 금색, 여성 03의 눈이 회색으로
보이던 문제를 수정했습니다. 머리카락 내부에서 연결된 영역만 찾아 색을 변경하고,
피부로 분리된 눈동자는 원래 색과 명암을 유지합니다. 동일한 처리 경로를 사용하는
다른 외형에도 이 보호 규칙을 적용합니다. 대기 1장과 이동 2장 모두 검사합니다.

검증은 남녀 8종의 눈·귀·볼 픽셀을 승인된 원본과 직접 비교하며, 남성 03/여성 03의
머리색은 여전히 구분되는지 확인합니다. 어깨의 크림색 옷깃은 승인된 원본에 포함된
표현으로, 이번 얼굴색 수정에서는 그대로 유지했습니다.


## 버전 0.0.10

밝은 머리색을 RGB 채널별로 곱하던 방식이 피부와 머리카락이 섞인 경계 픽셀을 흰색으로
포화시켜 금발·은발 얼굴 둘레에 밝은 선이 생겼습니다. 머리색을 제한된 중간색·밝은색
범위로 변환하고, 경계는 인접한 머리·피부 색으로 혼합 비율을 추정해 머리 성분만

## 버전 0.0.34

월드맵에서 산·강·물 지형을 우회하는 길찾기를 적용했습니다. 강 위의 더 높은 레이어에 도로가 있는 두 다리 구간은 통행할 수 있습니다. 대각선 모서리 통과를 막고, 이동 중 재명령도 현재 위치에서 경로를 다시 계산합니다. 이동 불가 또는 도달할 수 없는 지점에는 빨간 X 커서를 표시하며, 해당 지점을 클릭해도 기존 이동 명령은 유지합니다.

지도 그림과 타일 배치는 유지됩니다. 통행 정보는 실제 타일 종류/레이어 순서로 자동 생성하고 경로는 명령 시에만 계산합니다. 월드맵 캐릭터는 무기 없는 대기 첫 프레임으로 고정되며 전투맵 이동 방식은 유지됩니다.

## 버전 0.0.35

월드맵 이동 판정을 실제 물/산/다리 이미지에서 추출한 4px 격자로 세분화했습니다. 다리 타일의 위아래 강물은 막고 다리 바닥만 통과하며, 산의 투명 여백은 통행 가능합니다. 커서와 길찾기는 같은 보수적 판정을 사용합니다. 첫 월드맵 진입은 300% 배율과 플레이어 중앙 시점이며, 전투맵 왕복 시에는 기존 시점/배율을 복원합니다. 지도 원본과 전투맵 동작은 유지합니다.
