MedievalMap — 월드맵 구상도 반영본

열기
1. ZIP을 폴더째 압축 해제합니다.
2. Tiled에서 MedievalMap.tiled-project를 엽니다.
3. WorldMap.tmx를 열면 편집할 수 있습니다. WorldMap.tmx를 직접 열어도 됩니다.
4. Tiles 폴더와 .tsx 파일을 같은 구조로 유지해 주세요.

지도
- 160×120칸, 한 칸 32×32픽셀, 전체 5120×3840픽셀입니다.
- 보내주신 구상도의 바다/호수/강, 산맥, 숲과 빨간 도시 위치를 기준으로 배치했습니다.
- 설원으로 표시된 북부도 기존 초원 바닥으로 구성했습니다.
- 그림의 지형 윤곽을 타일 격자에 맞춰 옮긴 배치이므로 세부 해안/강변은 근사입니다.
- 강이 끊겨 보이지 않도록 주요 강은 대체로 3칸 폭의 영역을 기준으로 구성했습니다.

도시
- City 레이어에는 사용자 샘플과 같은 96×96(3×3칸) 도시 42개만 있습니다.
- 원래 샘플의 9개 타일을 그대로 사용했습니다. 다른 건물/장식 오브젝트는 배치하지 않았습니다.
- 도시 위치는 구상도의 빨간 점을 32px 격자에 맞췄고, 중심 오차는 축별 16px 이내입니다.
- CityPoints는 1~42 번호와 중심 좌표를 보관하는 숨김 보조 레이어입니다.
- 지도 위 번호가 필요한 경우 Review/WorldMap_numbered.png를 참고하세요.

레이어
- Ground: 초원 기본 바닥
- Ground_Detail: 원본 잔디/숲 바닥 무늬
- Water: 바다, 호수, 주요 강과 물가
- Forest: 나무와 숲 묶음
- Mountains_1~4: 산맥 묶음. 원본 묶음 그림끼리 겹칠 때 잘리지 않도록 층을 나눴습니다.
- City: 지정된 도시만 배치
- CityPoints: 도시 번호/좌표, 기본 숨김

리소스
- 제공된 PNG 14장은 원본 바이트를 유지했습니다. 그림 재생성/재착색/크기 변경은 하지 않았습니다.
- ObjectsTiles.png의 실제 크기는 512×544입니다. 기존 TSX에 남아 있던 384px/12열 설정을
  실제 512px/16열/272타일로 맞췄습니다. 도시 타일 번호는 원래 샘플과 동일합니다.
- PixelMapCreator 예제 장면의 숲·산맥 묶음 배치를 참고했습니다.
- Road/Parchment 등 사용하지 않은 원래 타일셋 파일도 편집용으로 보관했습니다.

미리보기와 자료
- Review/WorldMap_full.png: Tiled 렌더러로 출력한 5120×3840 전체 지도
- Review/WorldMap_preview.png: 축소 미리보기
- Review/WorldMap_numbered.png: 도시 번호가 표시된 검토용 미리보기
- Review/cities.json: 도시 번호 및 타일/픽셀 위치
- Review/terrain-plan.json: 구상도 전사 참고 좌표. snow 항목은 참고 기록이며 실제 맵은 초원입니다.

검증
- 실제 Tiled 렌더링과 JSON 내보내기/타일 데이터 대조를 통과했습니다.
- 도시 42개의 타일 및 렌더링 픽셀이 원본 샘플과 일치하는지 검사했습니다.
- City 이외의 레이어에 ObjectsTiles의 타일이 없는지 검사했습니다.
- 모든 PNG 원본 해시, 타일 번호, 상대 경로, 출력 이미지 크기를 검사했습니다.

이번 파일은 Tiled 편집용 지도입니다. 게임 저장소나 웹 배포 버전은 변경하지 않았습니다.
